# SilverFox-Cleaner

银狐木马 (dmo/client) 检测清除工具 — 三实现多分支:

| 分支 | 实现 | 产物 |
|---|---|---|
| [`rust`](/tree/rust) | Rust v4.2 | silverfox-cleaner.exe (x64, 单击免装) |
| [`c`](/tree/c) | C 重写版 (NT6+) | SFCleaner_x86.exe / SFCleaner_x64.exe |
| [`winui3`](/tree/winui3) | WinUI 3 (.NET 8) | self-contained + MSIX |

全分支 GitHub Actions 自动构建 (带缓存), artifacts 可直接下载。
