# SilverFox Cleaner (Rust v4.2)

银狐 (dmo/client) 检测清除工具 — Rust 版。GUI + CLI，SFQENC1 时间戳加密隔离、还原/清空、极端模式（0xC0114514 蓝屏×2 + 安全模式清场 + 自毁）、不客气模式（自定义证书+内核驱动装载）。

构建: GitHub Actions (x86_64-pc-windows-gnu + 嵌入式 requireAdministrator 清单)。
本地: `bash build.sh`（需 mingw-w64 + rustup windows-gnu target）。
